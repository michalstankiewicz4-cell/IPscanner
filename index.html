EXAMPLE BLUEPRINTS
1) Timed single PC scan
At 22:30 scan 192.168.1.25 and save a TXT report on Desktop.
2) Nightly IP range audit
Every night scan 192.168.0.1-192.168.0.254, include open ports and response time trend.
3) Multi-site inventory sync
Scan three subnets, merge results, export CSV + JSON and generate a diff versus previous day.
4) Incident response chain
If new host appears on secure VLAN, run deep scan, snapshot HTTP title/fingerprint, send webhook alert.
5) IF condition: detect camera stream
After scan completes, IF port 8554 is open → TRUE path: send instant alert. FALSE path: write a "port closed" log entry.
